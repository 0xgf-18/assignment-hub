This app needs its Supabase keys before it can run. Open config.js and fill in the two values.

  1. Create a free project at supabase.com.
  2. Run supabase/schema.sql in the Supabase SQL Editor.
  3. Copy Project URL and the anon / publishable key from Project Settings → API into config.js.
  4. Publish this folder to GitHub Pages and reload.
window.APP_CONFIG = {
  SUPABASE_URL: "https://YOUR-PROJECT.supabase.co",
  SUPABASE_ANON_KEY: "YOUR-ANON-KEY"
};
